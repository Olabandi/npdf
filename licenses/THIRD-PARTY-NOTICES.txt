=============================

licence named here. The full licence texts, copyright notices and NOTICE files are in the
sub folders of this "Licenses" folder, unchanged from the original source.

This file is updated together with the components (build/update-licenses.ps1 collects the texts;
a test checks that the PDFium licence folder matches the PDFium version in use).

Modifications

All other components are used as published, without changes.


NOTICE files
------------

Where a component contains a NOTICE or THIRD-PARTY-NOTICES file, it is included unchanged in the
component's folder (C#/WinRT, SkiaSharp, HarfBuzzSharp, Microsoft.Extensions). PDFium and the other
components do not contain a NOTICE file.
